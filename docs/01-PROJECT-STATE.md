# Состояние и требования

WinterDesk — переносимое оформление рабочего стола Windows: снегопад, сугробы внизу и на окнах, интерактивные комы, живые снеговики, пингвины, белка, гирлянды и Санта. Версия сборки 2.3.0.0. C# / WinForms / System.Drawing / Win32 layered windows, .NET Framework 4.x. Распространение — один EXE со встроенными ресурсами.

## Требования владельца, которые следует сохранять
- Акварельный рисованный стиль персонажей, сугробов и непрозрачных снежных комов; ориентир — ранняя классическая рисованная анимация. Полноценные позы вместо наклона целой картинки или приклеенной конечности. Санта с упряжкой — единый рисунок.
- Полупрозрачное меню, крупные кнопки в один вертикальный столбец, текст целиком помещается. Не возвращать удалённые пользователем кнопки: пауза, сугроб, отдельная гирлянда, намести снег, убрать пингвинов/снеговиков, очистить снег, пингвин с лопатой, Санта сейчас/по расписанию. Кнопка переключения режимов гирлянды нужна.
- Гирлянда без еловых веток, крупные лампы, естественный упорядоченный провод с разнообразием изгибов. На уровне заголовка окна, не перекрывает системные кнопки. Режимы мигания/цветов/затухания.
- Пингвин шагает, плавно бросает снег; после падения садится, встаёт, отряхивается и убегает без секундной неподвижности. Приветственное махание убрано. В удержании машет крыльями. Захват уборщика прекращает уборку. Падающий и убирающий пингвины одинаковы по видимому росту. Сохранить уменьшение и более стройный силуэт уборщика.
- Снеговик может смотреть в обе стороны, реально сгибается при катании кома, двигается при захвате и падении. Автоматически падает раз в 10 минут, строит одного потомка; потомок никого не строит. Захват не обнуляет счётчик.
- Белка приходит с края экрана, прыгает с настоящих опор, цепляется к краю высокого окна одним прыжком и быстро карабкается, затем перелезает наверх. Её можно схватить, перенести и отпустить. Не чаще раза в 5 минут. Подъём до 2,2 с, максимум три повтора, перелезание 0,55 с.
- Снежинки обычного режима крупные, как понравившиеся пользователю снежинки вьюги. Снежные шапки с округлениями/свисаниями, без резкого среза. При закрытии/сворачивании окна снег падает вниз.
- Ком растёт только при реальном контакте с сугробом; в воздухе снег снизу не собирается. Сохранение массы, бросок мышью по инерции, удар и распад об окно. Три уложенных кома оживают там, где собраны, включая верх открытого окна.

## Последняя правка 2.3
AwakenStack берёт основание реальных комов, передаёт его в AdoptStackBase. Оживший снеговик привязывается к окну и следует за ним; при закрытии опоры падает с её высоты. Старое поведение телепортировало конструкцию на нижнюю поверхность.

## Статус достоверности
Эти пункты — требования и заявленное поведение реализации. Код компилировался и модели проверялись автоматически, но это не свидетельство идеальной плавности на настоящем Windows. Визуальные замечания владельца требуют реального запуска. Приложение нельзя считать гарантированно свободным от ошибок.
