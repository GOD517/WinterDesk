# Запрос для следующей нейросети

Продолжи мой проект WinterDesk из приложенного пакета. Сначала прочитай docs/00-START-HERE.md и остальные документы, затем код актуальной версии WinterDesk-2.3. Не начинай проект заново. Это C# WinForms/Win32 приложение для Windows, распространяемое одним EXE со встроенными рисунками. Сохрани существующий стиль и функции.

Сначала сообщи, смогла ли ты собрать исходники и какие проверки реально доступны в твоей среде. Не называй модельные Linux-тесты проверкой реального интерфейса Windows. Не удаляй лимиты памяти, фоновую подготовку кадров и защиту от утечек. Отдельные рисунки персонажей не заменяй наклоном целой картинки или приставленной конечностью.

Незавершённая задача — публикация релиза в GOD517/WinterDesk и безопасное автообновление с пунктом меню. В версии 2.3 этого механизма ещё нет. Перед реализацией проверь текущее состояние репозитория, предложи конкретный порядок работ и продолжи после моего выбора. Не публикуй исходники в открытом репозитории: там нужны готовые EXE. Не проси прислать пароль или токен в чат. Если доступа нет, объясни ограничение и дай точные шаги.

Архив переписки, если я приложу его отдельно, используй для уточнения решений. Более поздние мои указания имеют приоритет. В документах есть прежние неподтверждённые на Windows заявления о поведении — не воспринимай их как гарантию отсутствия дефектов.
