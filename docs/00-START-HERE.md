# Передача WinterDesk 2.3 — 15 ноября 2026

Это автономный пакет исходников и документации для продолжения разработки в другой среде или нейросети. Он не требует доступа к ChatGPT. Читайте документы по порядку. Источник кода: последний сохранённый архив WinterDesk-2.3-source.zip; код не переписывался при упаковке.

## Содержимое
- WinterDesk-2.3/: C# исходники, build.ps1, манифест, исходные изображения и упакованные кадры.
- work/: сохранённые автоматические проверки и Linux-сценарии сборки версии 2.3.
- release/WinterDesk-2.3.exe: последняя готовая программа, без необходимости сборки.
- docs/: эта документация, карта проекта, требования, проверки, задачи и стартовый запрос следующей нейросети.
- MANIFEST-SHA256.json: размер и SHA-256 каждого файла пакета.

## Первые действия
1. Прочитать 01-PROJECT-STATE.md и 02-ARCHITECTURE.md.
2. Собрать программу по 03-BUILD-AND-TEST.md без изменения исходников.
3. Проверить её на Windows по 05-WINDOWS-QA.md.
4. Согласовать с владельцем следующую задачу; текущий незаконченный этап — выпуск на GitHub и автообновление.

## Граница резервной копии
Это резервная копия проекта и технического контекста, а не дословный экспорт всей переписки. В него не входят скрытые сообщения, недоступные вложения, все старые EXE и все промежуточные версии. Владелец отдельно сохраняет переписку. Нельзя обещать, что описания заменяют её полный архив. Все активные ресурсы для сборки входят в пакет; исторические скрипты генерации рисунков могут отсутствовать.

Исходный README и ASSETS сохранены для истории. При противоречиях текущий код и документы передачи имеют приоритет над устаревшими описаниями. В частности: у автоматического снеговика один потомок; репозиторий для обновлений уже выбран. Не публикуйте исходники автоматически: владелец хотел распространять EXE без публикации кода.
