# План обновлений WinterDesk

Это проект механизма обновления, а не подключённый сервис. В сборке 2.3 нет автоматического скачивания и установки обновлений: постоянный адрес публикации ещё не выбран.

## Что нужно владельцу программы

- Постоянное HTTPS-хранилище для готовых EXE и метаданных версии. Подойдёт GitHub Releases или собственный HTTPS-сайт. Исходники публиковать необязательно.
- Постоянный адрес сведений о последней версии. Приложение запрашивает этот адрес при запуске и затем, например, раз в 6 часов; сетевые запросы выполняются в фоне с тайм-аутом.
- Для каждого выпуска: версия, URL EXE, размер, SHA-256, описание изменений и цифровая подпись метаданных. Закрытый ключ хранится у владельца, в приложение встраивается только открытый ключ проверки. Токен публикации не встраивается в EXE.
- Папка установки, доступная пользователю для записи. Для обновлений без прав администратора подходит папка приложения в LocalAppData; переносимая версия также требует права записи в свой каталог.

## Поведение меню

- Обычное состояние: «Проверить обновления».
- После обнаружения проверенной более новой версии: «✓ Доступно обновление 2.x».
- Нажатие скачивает обновление во временный каталог, показывает прогресс и проверяет размер, SHA-256 и подпись.
- Только после проверки приложение закрывается, временный помощник заменяет EXE с резервной копией и запускает новую версию.
- При неудаче установки сохраняется рабочая версия. Нужны проверка успешного запуска и откат. Отсутствие сети не прерывает анимацию.
- В постоянном распространении остаётся один EXE; служебный помощник может быть временной копией этого же EXE с отдельным режимом запуска.

## Публикация

Владелец публикует готовый EXE новой версии и соответствующие подписанные метаданные. Клиент сам обнаруживает изменение номера версии. Проверка и скачивание не должны зависеть от этого чата или авторизации в ChatGPT.

## Перед подключением

Нужен адрес GitHub-репозитория для выпусков либо HTTPS-каталог сайта. После выбора адреса можно реализовать клиент, подпись выпусков, пункт меню, установку и откат и проверить полный цикл на Windows.
