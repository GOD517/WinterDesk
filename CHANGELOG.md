# Изменения

## 2.4.0

- Компактная кнопка «Обновить» в нижней части панели.
- Зелёный флажок с номером доступной версии.
- Фоновая проверка GitHub Releases при запуске и раз в 6 часов.
- Загрузка по нажатию, проверка RSA/SHA-256, размера и версии файла.
- Замена EXE с резервной копией, перезапуском и откатом при неподтверждённом запуске.
- Общий источник номера версии для панели, меню и механизма обновления.
- Сборка и тесты на Windows, история проекта на GitHub.

## 2.3

Исходная переданная версия: зимняя сцена и интерактивные персонажи без сетевого обновления.
