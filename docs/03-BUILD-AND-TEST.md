# Сборка и проверки

## Windows
1. Распаковать весь архив. Нужен Windows с .NET Framework 4.x и доступным компилятором csc.exe по пути, указанному в build.ps1.
2. Открыть PowerShell в WinterDesk-2.3 и выполнить: `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1` (политика меняется только для этого запуска).
3. Скрипт создаёт WinterDesk-2.3.exe рядом с исходниками, встраивает три ресурса и манифест. NuGet и отдельные DLL проекта не нужны.
4. Закрыть прежнюю программу через значок у часов, затем запустить новый EXE. Не смешивать версии при проверке.

Скрипт жёстко ожидает Framework64/v4.0.30319/csc.exe; на другой конфигурации исправить путь к установленному компилятору, сохранив ссылки System, System.Core, System.Drawing, System.Windows.Forms, System.IO.Compression, параметр unsafe и имена ресурсов. Файл .csproj в текущем проекте отсутствует. При его создании не забыть все C# файлы и embedded resources. Пакет не включает установщик .NET или SDK.

## Сохранённые Linux-проверки
work/build23.sh и work/test23.py перенесены без изменения. Они запускаются из корня пакета и ожидают локальный каталог toolchain/ с Mono, который НЕ включён (это зависимость среды разработки, а не часть приложения). Для другой Linux-среды заменить абсолютные/относительные пути Mono и библиотек на установленные там. Python 3 нужен тестовому адаптеру.

`bash work/build23.sh checks` компилирует приложение и вызывает тестовый сценарий. test23.py подменяет только Sprite в сгенерированном work/Native23Test.cs на управляемый Bitmap-адаптер; production Native.cs не меняется. Это проверяет логику и освобождение тестовых буферов, но не реальный DIB/Win32.

## Что уже проверялось в ходе разработки
Компиляция; доступность кадров/псевдонимов; фоновая загрузка атласа, лимиты кэшей и отмена; контакт кома и сохранение массы (1000 циклов); 32 маршрута белки; интервалы 5/10 минут без накопленной очереди; один потомок; видимый рост пингвинов; классификация событий окон, перенос массы при resize; ручная сборка на окне и падение после удаления опоры; 60 минут имитируемой физики и 360 захватов/отпусканий. Полные утверждения — в Checks23.cs. Это имитация времени, а не час реальной работы интерфейса.

Тесты в этом пакете сохранены из предыдущей проверки. При упаковке выполнены сверка байтов исходников, проверка ZIP и контрольных сумм; нативный запуск Windows заново не выполнялся.
