# WinterDesk

Акварельная зима на рабочем столе Windows: падающий снег, сугробы на окнах, гирлянды, пингвины, снеговики, белка и Санта с упряжкой.

## Скачать

[Последняя версия для Windows](https://github.com/GOD517/WinterDesk/releases/latest/download/WinterDesk.exe) · [Все выпуски](https://github.com/GOD517/WinterDesk/releases)

Скачайте `WinterDesk.exe` в свою папку и запустите. Установщик и права администратора не нужны. Требуется Windows с .NET Framework 4.8. Выход — через значок у часов или Ctrl+Alt+Shift+Q.

## Обновления

Начиная с 2.4.0 программа проверяет выпуски через 6 секунд после запуска и затем раз в 6 часов. Внизу панели есть компактная кнопка **Обновить**. Зелёный флажок **Доступно обновление** появляется после проверки более новой подписанной версии. Если обновления пока нет, кнопка запускает повторную проверку.

Нажатие при доступном обновлении скачивает новый EXE, проверяет подпись RSA/SHA-256, размер, версию и контрольную сумму. Программа перезапускается после замены. Рядом сохраняется резервная копия `*.previous-*.bak`; если новый процесс не подтверждает запуск, выполняется откат. Для установки нужна запись в папку EXE. Работа анимации не зависит от наличия сети.

На компьютерах с 2.3 нужно один раз вручную заменить программу на 2.4.0 или новее. Токены GitHub и закрытый ключ подписи в программу не включены.

## Сборка и проверки

```powershell
.\build.ps1
.\tests\Run-Checks.ps1
```

Результат сборки: `dist/WinterDesk.exe`. Исходники и готовые ресурсы находятся в `src`. В проекте используются C#, WinForms, System.Drawing и Win32 layered windows. Внешние NuGet-зависимости отсутствуют. Готовые ресурсы переданы с проектом; исходные скрипты их генерации не входят в архив.

Большой архив анимации `drawn-animation.zip` хранится во вложениях выпуска 2.4.0. При первой сборке скрипт скачает его и проверит закреплённую SHA-256; нужен интернет. Остальные ресурсы находятся в репозитории.

## Публикация новой версии

1. Измените версию в `src/AssemblyInfo.cs`, соберите приложение и выполните проверки.
2. Выполните `scripts/New-Release.ps1 -PrivateKeyPath <путь-к-закрытому-ключу>`.
3. Создайте выпуск с тегом `v2.4.0` (для соответствующей версии) и приложите `WinterDesk.exe`, `update.txt`, `SHA256SUMS.txt` из `dist`.
4. Сделайте выпуск последним стабильным и проверьте скачивание и обнаружение с предыдущей версии.

Закрытый ключ хранится отдельно от репозитория и необходим для последующих обновлений. Не публикуйте его. Автоматическая Windows-сборка проверяет код при push; публикация подписанного выпуска выполняется отдельно.

Документы из прежней передачи находятся в `docs` и описывают историческое состояние 2.3. Текущая инструкция — этот README.
