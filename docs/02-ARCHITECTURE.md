## Важные инварианты
Подготовка Bitmap выполняется в фоне; передача в нативные буферы порциями через FramePreparation.Pump. Не декодировать весь набор при появлении персонажа. FrameBank использует общую идентичность повторяющихся рисунков и ограничение памяти. Удалённый/отменённый объект не должен получать готовый буфер после Dispose.

DrawnPack хранит уникальные PNG и таблицу frames.txt с псевдонимами. 256 позиций уборщика используют 27 рисунков: позиции не равны числу вручную нарисованных кадров. Для построения EXE нужны три ресурса: drawn-animation.zip (WinterDesk.DrawnPack), decor-watercolor.png (WinterDesk.DecorSheet), penguin.ico (WinterDesk.PenguinIcon). Остальные ключевые PNG полезны для дальнейшего редактирования рисунков.

Ограничения сцены: 24 снеговика, 24 переносимых пингвина, 24 кома, 12 эффектов удара, один уборщик. Кэши снеговиков/белки ограничены; источники Bitmap имеют бюджет. Буферы снежных поверхностей переиспользуются. Не удалять эти ограничения ради новых функций без замеров.

Окно-опора определяется дескриптором и относительным смещением. Временное перекрытие не равно закрытию. События MinimizeStart (0x16), Destroy (0x8001), Hide (0x8003) отделяют снег; дочерние события фильтруются. Отделившаяся масса не должна отделяться повторно. При изменении размера SnowModel.Transfer сохраняет массу.

AdoptStackBase сохраняет фактическое основание ручной конструкции. Поддержка исчезла — переход в Falling, без телепортации. Один источник масштаба нужен для изображения, физики и хитбокса пингвина.
