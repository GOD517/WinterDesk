Предложенная схема (ещё не код):
1. Проверять подписанные метаданные последнего выпуска фоновым запросом с тайм-аутом при запуске и примерно раз в 6 часов.
2. Меню «Проверить обновления» / «✓ Доступно обновление …», прогресс загрузки.
3. Метаданные: версия, URL, размер, SHA-256, описание, подпись. В приложении открытый ключ, закрытый ключ только у владельца. SHA-256 без доверенной подписи не подтверждает авторство.
4. Скачать во временный файл, проверить, затем временный помощник (возможен режим --apply-update того же EXE) ждёт завершения процесса, заменяет EXE с резервной копией, запускает и обеспечивает откат.
5. Обработать отсутствие сети, повторный запуск, отмену, заблокированный EXE, недостаток места/прав, неподходящий файл и сбой новой версии. Не блокировать анимацию и не встраивать GitHub токен.
6. Проверить полный переход между двумя реальными версиями на Windows, отказ подписи и rollback. Выбрать доступный пользователю каталог LocalAppData либо переносимую папку с правом записи.
